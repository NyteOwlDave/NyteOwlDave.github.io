Using Docify

Most of the methods are basic and self-explanatory. They're there for Run-Time Diagnostics and Code Spelunking.

I won't dwell on those. Try them yourself in the Footer Command Input. Click any suggestion below.

The real Star here is the docify method itself.

Suggestions

  • type( doc )
  • ntype( doc.body )
  • asize( Array.from( doc.scripts ) )
  • osize( new Set( [ 4, 2, 9 ] ) )
  • clist( ghost_anchor )
  • cname( ghost_editor )
  • ctype( Example )
  • ctype( new Example() )
  • hints( location, 'Location Members' )
  • hints( describe, 'Describe Members' )
