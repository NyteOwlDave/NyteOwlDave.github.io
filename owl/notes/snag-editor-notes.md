<h3 id="_T_"> Snag Editor Notes </h3>

----------------------------------------------------------------

# Description

This new tool will _display_ and _edit_
__Snaggy Dot Menu__ ( JSON ) files.

It should also provide __Documentation__ about `JSON` file
_schema_ and common _use-cases_.

----------------------------------------------------------------

# Proposed Features

----------------------------------------------------------------

- __File I/O__
    - Read Snaggy Manuscript JSON
    - Write Snaggy Manuscript JSON 

----------------------------------------------------------------

- __Icons__
    - Show Individual Icons ( when Asked )
    - Drop List for Icons
    - Show Records for Icons

----------------------------------------------------------------

- __Dot Menus__
    - Show Records for Dot Buttons
    - Form Table for Editing Entries
    - Normal Table for Entry Summary
    - Drop List for Entry Titles and TiKeys

----------------------------------------------------------------

- __Dot Buttons__
    - Show Records for Dot Buttons
    - Form Table for Editing Entries
    - Normal Table for Entry Summary
    - Drop List for Entry Titles and TiKeys
