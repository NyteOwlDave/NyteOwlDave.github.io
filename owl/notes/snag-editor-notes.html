Snag Editor Notes

Description

This new tool will display and edit Snaggy Dot Menu ( JSON ) files.

It should also provide Documentation about JSON file schema and common use-cases.

Proposed Features

  • File I/O
    • Read Snaggy Manuscript JSON
    • Write Snaggy Manuscript JSON
  • Icons
    • Show Individual Icons ( when Asked )
    • Drop List for Icons
    • Show Records for Icons
  • Dot Menus
    • Show Records for Dot Buttons
    • Form Table for Editing Entries
    • Normal Table for Entry Summary
    • Drop List for Entry Titles and TiKeys
  • Dot Buttons
    • Show Records for Dot Buttons
    • Form Table for Editing Entries
    • Normal Table for Entry Summary
    • Drop List for Entry Titles and TiKeys
  • Schema Notes
    • ( pending )
