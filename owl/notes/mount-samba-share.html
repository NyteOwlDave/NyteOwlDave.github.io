Response

To mount an SMB share from the Ubuntu terminal, you use the mount -t cifs command.

Here is how to do it manually, followed by how to set up an automatic persistent mount.

Step 1: Install Dependencies

You need the cifs-utils package installed to handle SMB/CIFS connections.

Bash Scripts


sudo apt update && sudo apt install cifs-utils -y

Step 2: Create a Local Mount Point

Create the local directory where you want the network folder to appear.

Bash Scripts


sudo mkdir -p /mnt/[VOLUME]
Where: [VOLUME] is a placeholder

Method A: Mount Manually (Temporary)

Run the following command, replacing the placeholder information with your actual server IP, share name, and username:

Be advised that mounting will request a password to log in to the Samba Service. This means the process can't be automated using this Method.

Bash Scripts


# Mount

sudo mount \
-t cifs    \
-o username=YOUR_USERNAME,uid=$(id -u),gid=$(id -g)  \
//[IP]/[SHARE] \
/mnt/[VOLUME]

# Unmount

sudo umount /mnt/[VOLUME]
Where:
  • [IP] is a placeholder
  • [SHARE] is a placeholder
  • [VOLUME] is a placeholder

Method B: Mount Automatically on Boot (Persistent)

Instead of putting your password directly in a public text file, create a hidden credentials file for security.

Step 1. Create a credentials file:

Bash Scripts


nano ~/.smbcredentials

Step 2. Add Credentials

Bash Scripts


username=YOUR_USERNAME
password=YOUR_PASSWORD

Save and exit.

Step 3. Secure File Permissions

Bash Scripts


chmod 600 ~/.smbcredentials

Step 4. Edit the FSTAB Table


sudo nano /etc/fstab

Step 5. Make These Changes


# Append at bottom of fstab

//SERVER_IP/SHARE_NAME     \
/mnt/[VOLUME] cifs         \
credentials=/home/[USER]/.smbcredentials,uid=[UID],gid=[GID],iocharset=utf8 0 0
TIP

Use the id command for [UID] and [GID].

The [VOLUME] placeholder was chosen earlier.

Step 6. Test


sudo mount -a
TIP

Step 6 reads config details from fstab

This means that multiple mount points are possible. Just repeat the process for editing that file.
