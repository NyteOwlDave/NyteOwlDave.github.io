----------------------------------------------------------------

collections of URL Addresses. I refer to this as the "Realms"
concept. Not to be confused with __Rhett's ReText Realms__.

----------------------------------------------------------------

This concept includes two __Global Symbols__. One for state
and the other for methods.

----------------------------------------------------------------

| Member | Type     | Description |
|--------|----------|----------------------------------|
| places | Object   | URL Address Map (state)          |
