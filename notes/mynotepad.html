🧙 Examples

Store Methods


ops = MyNotepad;

// Recover Notes from Store
if ( ops.recoverable ) {
    ops.recover();
}

// Persist Notes to Store
if ( ops.persistable ) {
    ops.persist();
}

Info Methods


// Show Members in Console
ops.assist();

// Show Summary in Console
ops.summary();
